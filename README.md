# Volt — Appliance Energy Consumption Website

Volt explains Australian energy labels in plain language, starting with the appliance that runs longest in most homes: the television. The site walks through the Australian Government's Television Energy Rating dataset and presents the findings as a data story, helping consumers compare screen technologies, sizes, brands, and running costs.

## Pages

| File            | Description                                                                 |
|-----------------|-------------------------------------------------------------------------------|
| `index.html`    | Home page — introduces the site and links to the Televisions page.            |
| `television.html` | Main data story — energy label explainer plus 8 investigation questions, each with a chart and short analysis. |
| `about.html`    | About Us page.                                                                 |
| `style.css`     | Shared stylesheet for all pages (brown theme).                                |
| `script.js`     | Shared JavaScript (e.g. status bar text).                                     |

## Running the site locally

No build tools or server are required.

1. Download/clone the project folder, keeping all files and the `images/` folder in the same relative structure shown above.
2. Open `index.html` directly in a web browser (double-click it, or right-click → Open with → your browser).
3. Navigate between pages using the top nav bar (Home / Televisions / About Us).

## Data source

Charts and figures on the Televisions page are based on the Australian Government's Television Energy Rating dataset. The 30c/kWh rate used for cost estimates is a placeholder for illustration only, not an official tariff.

## Investigation questions covered

1. What types of TV screen technologies are currently available in Australia, and which are the most frequent?
2. What screen sizes are available, and which are the most frequent?
3. Which brands have the largest number of models?
4. Which type of screen technology consumes the least amount of power?
5. What is the relationship between screen size and power use?
6. What is the relationship between star rating and screen size?
7. Are there differences in power consumption between brands?
